### Что есть сейчас

- Почти полностью переделан дизайн. Остается только основная страница с видео
- Хранение видео в облаке
- Базовые функции: Удаление, добавление, регистрация, авторизация, выход из аккаунта.

### Чему научился

- S3. Работа с Яндекс Облаком
- UiKit. Простая, но крайне удобная css библиотека
- Django Templates. В старой версии проекта(в той, что была в 2023-2024 году) использовалась стандартная html разметка.
  Сейчас стало больше шаблонов
- Выделение бизнес логики. Убрал лишние функции из views

### Идеи будущего развития. (Идеи взяты из DeepSeek. Реализованы будут 2-3 идеи)

### 1. Фичи, напрямую улучшающие пользовательский опыт

+ Лента/алгоритм рекомендаций. Сейчас у вас, наверное, просто хронологическая лента. Сделайте простую систему:
  сортировка по количеству лайков/просмотров, показ видео от тех, на кого пользователь подписан, и "популярное" от всех.
+ Система подписок и избранное. Две отдельные вкладки в профиле: "Мои видео" и "Избранное" (лайкнутые) или "
  Понравившиеся". И вкладка "Подписки" в главной ленте.
+ Просмотры. Простой счетчик, который увеличивается при каждом открытии видео. Показывает популярность контента.
+ Хештеги и поиск. Добавление тегов к видео и поиск по ним. Это классическая и очень полезная задача (связь
  Many-to-Many).
+ Закладки ("Сохранить"). Отдельно от лайков. Пользователь может сохранить видео, чтобы посмотреть позже.
+ История просмотров. Простая страница, где пользователь видит, что он недавно смотрел.

### 2. Технические и инфраструктурные улучшения

+ Кеширование. Использование Django Redis или Memcached для кеширования ленты популярных видео, топовых пользователей.
  Очень крутая тема для собеса.
+ Фоновая обработка задач (Celery + Redis/RabbitMQ). Идеально для:
+ Генерация превью для видео (скриншот из середины).
+ Конвертация загруженного видео в единый формат (например, mp4 с одним разрешением).
+ Оптимизация изображений аватарок.
+ Отправка email-уведомлений (о новых комментариях, подписчиках).
+ Пагинация (бесконечный скролл). На главной странице. Уменьшает начальную нагрузку и улучшает UX.
+ REST API (Django REST Framework). Выделите API для всех основных операций (получить ленту, поставить лайк, оставить
  комментарий). Это откроет путь к будущему мобильному приложению и покажет знание современных подходов. Супер-плюс для
  Junior+.

### 3. Фичи для взаимодействия и модерации

+ Ответы на комментарии (древовидные комментарии). Сложнее, чем плоский список, но очень круто.
+ Жалобы на контент (модерация). Простая форма отправки жалобы админу. В админ-панели — очередь жалоб.
+ Прямые сообщения (DM) или чат между пользователями. Можно начать с простого — форма отправки сообщения другому
  пользователю, а в профиле — список входящих.
+ Трансляции (Live Streaming). Очень сложная, но "хайповая" фича. Можно начать с интеграции с YouTube Live или простым
  решением на WebRTC.

### 4. Для профиля и аналитик.

+ Редактирование профиля (вы уже планируете) + загрузка аватарки/обложки.
+ Приватные/скрытые видео. Видео видны только автору или по прямой ссылке.
+ Простая аналитика для автора. На отдельной странице: график просмотров и лайков за последние 7/30 дней к своим видео (
  можно с помощью Chart.js).

### 5. Безопасность и надежность

+ Rate Limiting. Защита от спама (например, не более 10 лайков в минуту, 5 комментариев).
